# Changelog

## 1.1.2
- Authors changed to HighBitRate and IbuprofenRP. The code package is now `dev.highbitrate.chattoolkit`.

## 1.1.1
- "Remove from chat" in the right-click menu.
- With Chat Animation installed, messages that go to another tab no longer make the main chat slide.
- Presets can be exported to and imported from files in `config/chattoolkit/presets`, or dragged onto the game window.

## 1.1.0
- Chat tabs on top of the message box, with red dots for new messages.
- Tabs can pop out into windows you can move, resize and scroll, and drag back to dock.
- Tab editor with rules that match how a message looks (& color codes), send-as commands, colors and presets.
- Built-in SRP default preset (RP, OOC, LOOC, Friends) and presets that load per server.
- How to Use page.

## 1.0.3
- The pinned notes panel can be dragged anywhere while chat is open.

## 1.0.2
- Search bar lines up with the chat box edge to edge, no magnifier, dimmer placeholder.
- New icon.

## 1.0.1
- Clicking the search bar to type works reliably.
- Search bar matches the chat input look.
- Chat moves above health bars in survival.
- Plainer command messages and settings text.

## 1.0.0
- First release: chat search, right-click menu, /ccalc, /cnote, /ctimer, /ccoords, settings screen with Mod Menu support.
